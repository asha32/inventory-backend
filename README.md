Inventory Management System – Backend
About the Project
A REST API built using Node.js and Express.js to manage inventory items. It supports CRUD operations, filtering, searching, input validation, and error handling.
Technologies Used
- Node.js
- Express.js
- JavaScript
- REST API
- Hoppscotch
- Nodemon
- dotenv
- CORS
Features
- Add new inventory items
- View all inventory items
- View a single item by ID
- Update inventory items
- Delete inventory items
- Filter items by category and quantity
- Search items by name
- Input validation
- Centralized error handling
